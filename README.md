

##### The project was created on the intend to perform the creation of a generic ETL algorithm that giving any file csv, it can create the table, columns and insert the respective data into it.

Surucua_ETL.py – The main part of the algorithm that calls the ManageFile.py and ManageData.py in order to create the tables and columns in order to insert the data.

ManageFile.py – Responsible to read the csv file and get the file name and the columns. 

ManageData.py – Responsible to connect to the database and insert the data read from the CSV file.

Disclaimer – For the development of the code there was no use of any AI tools at all.
